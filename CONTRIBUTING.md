# Contributing to AIC8800D80 Kernel Patches

Welcome! We strictly appreciate your interest in helping make the AIC8800D80 USB Wi-Fi adapter compatible with Linux Kernel 7.x+.

## Code of Conduct

- Treat fellow contributors with respect and professionalism.
- Technical disagreements must be backed by documentation or testing results.
- No brand names, corporate affiliations, or organizational branding are allowed in PR titles, commit messages, or code comments. Keep this strictly FOSS.

## How to Submit Patches

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-kernel-update`.
3. Add your patches with clear, detailed commit messages.
4. Push your branch and open a Pull Request.

## Coding Standards

- All patches must be unified diffs (`git diff -U10`).
- Follow existing kernel coding styles strictly.
- Ensure compatibility across at least two consecutive 7.x kernel minors.
